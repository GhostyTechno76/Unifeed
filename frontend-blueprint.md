# Frontend UI Blueprint & Component Checklist

---

## AI System Prompt for Frontend Generation

> Copy and paste this prompt to any coding agent or AI assistant tasked with generating the frontend UI components:

```markdown
You are an expert Frontend Design Engineer building the user interface for the IIIT Bhubaneswar Campus Problem-Reporting Platform.
Technical Stack Requirements:
- Next.js (App Router, React 18/19, TypeScript)
- Styling: Tailwind CSS exclusively (utility classes only). DO NOT create separate .css or .module.css files.
- Icons: Use `lucide-react` for all icons (e.g., AlertCircle, ThumbsUp, Sparkles, LogIn, LogOut, CheckCircle, Clock).
- State & Data Fetching: Standard React state hooks (useState, useEffect) with native fetch() targeting the Edge API routes in `/api`.
- Store the authenticated user session (role, token, student_id) in React Context or localStorage.
- Theming & Aesthetic: Modern, clean campus portal aesthetic (Navy Blue, Slate Grey, and Accent Amber/Indigo). Responsive mobile-first design.
```

---

## UI Component Checklist

### 1. Global & Layout Components
- [ ] **`Navbar.tsx`**
  - Displays IIIT Bhubaneswar branding / logo.
  - Role badge indicator (`Admin` in purple/blue pill, `Student` in green pill).
  - User email display and `Log Out` button (`lucide-react: LogOut`).
- [ ] **`RoleGuard.tsx`**
  - Wrapper component that protects `/admin` routes from student access and redirects unauthenticated users to `/login`.
- [ ] **`ToastNotification.tsx`**
  - Floating alerts for successful problem submission, copy events, or network errors.

---

### 2. Authentication Flow (`/login`)
- [ ] **`LoginForm.tsx`**
  - Email input field with instant validation (`@iiit-bh.ac.in` suggestion pills).
  - Quick-login demo buttons (`"Login as Student"` and `"Login as Admin"`) to accelerate live pitch presentations.
  - Submit button with spinner loading state.
  - Submits to `POST /api/auth/login`.

---

### 3. Student Portal (`/student`)
- [ ] **`StudentHeader.tsx`**
  - Greeting banner displaying current student status and count of campus problems reported.
- [ ] **`ProblemSubmitForm.tsx`**
  - Title input with character count indicator (`min 3 chars`).
  - Detailed Description textarea with auto-expand (`min 5 chars`).
  - Clear submission feedback with `CheckCircle` confirmation banner upon `POST /api/problems/submit`.
- [ ] **`MySubmissionsList.tsx`**
  - Card feed showing tickets created by the logged-in student.
  - Status badges: `Unresolved` (amber pill with `Clock` icon) or `Resolved` (emerald pill with `CheckCircle`).

---

### 4. Admin Grievance Portal (`/admin`)
- [ ] **`AdminControlBar.tsx`**
  - Metrics cards: Total Complaints, Unresolved Count, High-Priority Issues (>10 upvotes).
  - Sort toggles:
    - `"Most Upvoted"` button (`lucide-react: Flame` or `ThumbsUp`) ➔ triggers `?sort=upvotes`.
    - `"Newest First"` button (`lucide-react: Calendar`) ➔ triggers `?sort=newest`.
- [ ] **`ProblemCard.tsx`**
  - Problem title, description, and timestamp relative formatter (e.g., *"2 hours ago"*).
  - Upvote count pill with bold contrast.
  - Submitter email chip (`student@iiit-bh.ac.in`).
  - Status badge (`unresolved`).
- [ ] **`AISummaryTrigger.tsx`**
  - High-visibility banner featuring a `"Generate Executive AI Summary"` button with `Sparkles` icon.
  - Displays active loading pulse state (*"Llama 3 8B analyzing campus reports..."*).
- [ ] **`AISummaryModal.tsx` / `AISummaryCard.tsx`**
  - Renders the 2-paragraph executive brief generated by Cloudflare Workers AI.
  - Paragraph 1: Issues synthesis.
  - Paragraph 2: Actionable administrative recommendations.
  - Copy-to-Clipboard button with visual checkmark indicator.
  - Export as PDF / Email to Authorities mockup button.

---

### 5. Fallback & Empty States
- [ ] **`EmptyProblemsState.tsx`**
  - Displayed when no unresolved issues remain.
- [ ] **`SkeletonCard.tsx`**
  - Shimmer placeholders during API fetches.
